# Getting help

Tabularius is looked after by a small group of volunteers, so answers come on a best-effort basis and there is no
service-level agreement. This page says where each kind of message belongs.

| I want to… | Go here |
|---|---|
| Ask a question, share how I use it, or suggest an idea | [GitHub Discussions](https://github.com/sitotisai/tabularius/discussions) |
| Report a bug, a file that does not open, or a missing feature | [Issues](https://github.com/sitotisai/tabularius/issues/new/choose) (the forms ask for what we need) |
| Report a security vulnerability | Privately, as [SECURITY.md](SECURITY.md) says: **Security**, then **Report a vulnerability** on the repository. Never in a public issue. |
| Report a conduct problem | Privately, as [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) says |
| Write privately about something else (press, partnerships, a question that does not belong in public) | [hello@tabularius.dev](mailto:hello@tabularius.dev) |

Before you write, these pages answer most questions: [QUICKSTART.md](QUICKSTART.md), [troubleshooting](docs/troubleshooting.md)
and [known differences](docs/known-differences.md).

Please do not send a `.fmp12` file, a backup or real customer data by email or in an issue. If a file does not open, follow
[reporting a file that does not open](docs/reporting-a-file-that-does-not-open.md), which says what to send instead.
