# TABULARIUS_BACKUP_KEY

Since 0.1.0

| Setting | Value |
| --- | --- |
| Default | No backup encryption passphrase |
| Accepted values | Nonempty passphrase; an empty value stops `serve` |
| Restart needed | Yes for a running server. |
