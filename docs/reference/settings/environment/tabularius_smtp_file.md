# TABULARIUS_SMTP_FILE

Since 0.1.0

A file holding the SMTP account for `--send-mail` (`~/.openhbam/smtp` by default); `TABULARIUS_SMTP` holds it directly.

| Setting | Value |
| --- | --- |
| Default | ~/.openhbam/smtp |
