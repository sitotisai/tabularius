# Tabularius 0.1.0

First public release of Tabularius: an open-source (MIT) platform that opens and hosts FileMaker `.fmp12` files. It reads the file, converts it once into a SQLite store (`<name>.openhbam.sqlite`) beside the original (which is left as it was), and serves it through a REST API shaped like the FileMaker Data API, a web client with a design mode, a script engine, a calculation engine and a built-in MCP server for AI tools.

This is an early version with partial compatibility. Read **Known limits** below before moving a file.

## Install

On macOS or Linux (arm64 or x64), one command installs the single-file program: no separate Node installation is needed.

```sh
curl -fsSL https://github.com/sitotisai/tabularius/releases/latest/download/get.sh | sh
tabularius demo
```

The installer checks `SHA256SUMS` and puts `tabularius` in `~/.local/bin`; follow its PATH instructions if that directory is not on your PATH.

`tabularius demo` hosts a small sample app on this computer only, uses a free port, opens the browser if it can, gives `Admin` a random password that is printed once, and deletes everything when you press Ctrl-C.

Published asset availability is unverified in this offline review. When the release assets are available, you can also download a program with one of the names below. Check it with `sha256sum -c SHA256SUMS --ignore-missing` (`shasum -a 256 -c` on macOS) and make it runnable with `chmod +x`. A file saved by a browser is quarantined by macOS; clear that with `xattr -d com.apple.quarantine <file>`.

| System | File |
| --- | --- |
| macOS, Apple silicon | `tabularius-0.1.0-macos-arm64` |
| macOS, Intel | `tabularius-0.1.0-macos-x64` |
| Linux, x64 | `tabularius-0.1.0-linux-x64` |
| Linux, arm64 | `tabularius-0.1.0-linux-arm64` |
| Windows | `tabularius-0.1.0-windows-x64.exe`, only if it is listed below (Windows execution remains unverified; see `docs/release-builds.md`) |

The Linux programs need glibc (not Alpine). `QUICKSTART.md` covers the other ways to install, including from a checkout and with Docker. Each program has a software bill of materials (`*.sbom.cdx.json`), and the licence texts are in `THIRD-PARTY-NOTICES.md`, or `THIRD-PARTY-NOTICES-<system>.md` when the builds have different notices.

## What it does

- **Reads and hosts `.fmp12` files**, including Encryption at Rest files supplied with their passphrase: tables, fields, relationships, layouts, scripts, value lists, custom functions, accounts and privilege sets, records, and container files.
- **A Data API-shaped REST API.** `docs/data-api-compatibility.md` lists every endpoint, field, header and error code as supported, partial or missing. It is shaped like the FileMaker Data API, not a drop-in copy.
- **A web client** that draws existing layouts, with a design mode, and lets you build new layouts in HTML, CSS and JavaScript. `docs/web-client.md` lists rendering limitations.
- **Calculations and scripts** run on the server, with the limitations in `docs/known-differences.md` and `docs/script-steps-support.md`. The debugger uses a scratch copy by default; Record run records a scratch run for stepping backwards and forwards.
- **A built-in MCP server** for AI tools: explore a solution, find and edit records within the account's privileges, explain why a field holds a value (`explain_value`), and say what a rename or delete would break before it happens (`check_change_impact`).
- **No telemetry, analytics or update check.** Nothing leaves your computer unless you turn something on (`docs/privacy.md`).

## Security defaults

- **New passwords:** the CLI defaults to a minimum of 12 characters when a file has no explicit minimum. `TABULARIUS_MIN_PASSWORD_LENGTH` changes that default and the admin console password minimum; a file's own password policy can override the file-account minimum.
- **MCP:** `/mcp` requires authentication even on localhost. Bearer access requires a valid token; HTTP Basic account credentials are also supported. `tabularius mcp-token <folder>` prints the administrator token after the server has created it. Use account-scoped tokens to restrict access to that account's privileges.
- **Account API tokens:** by default they expire after 90 days, with an explicit maximum of 3650 days; `TABULARIUS_TOKEN_DEFAULT_DAYS` changes the default. The folder administrator MCP token does not have this expiry and must be protected separately.
- **Listening address:** `tabularius service install <folder>` defaults to `127.0.0.1:8080`. With `--https <domain>` it defaults to `0.0.0.0`; `--https local` and `--https lan` retain the loopback default. Plain `tabularius serve <folder>` also defaults to `127.0.0.1:8080` (the demo chooses a free port).

## Known limits

- **People use a browser.** There is no FileMaker Pro or FileMaker Go client for a file hosted here.
- **Passwords.** An enabled imported local account with an empty password can sign in from the server's own computer by default. Inactive accounts stay disabled, and the built-in Guest account is imported disabled. Imported local accounts whose non-empty passwords cannot be recovered need a new password (`tabularius passwd <folder> <database> <account>`). External accounts need their identity provider configured.
- **Native FileMaker plug-ins are not loaded.** Built-in replacements cover some plug-in functions; unsupported calls can give "?" or an MBS error text. See `docs/plugin-compatibility.md` for supported, partial and unverified behavior.
- **Scripts run on the server.** Outbound mail and web requests are off by default. Mail needs explicit server configuration; web requests need the file's Script network switch or server-wide permission. Interactive steps such as Show Custom Dialog work in the web client; unattended runs and unsupported steps have the limits in `docs/script-steps-support.md`. Compatibility not established there remains unverified.
- **The store is not the `.fmp12`.** Changes made here can't be written back into a `.fmp12` file.
- **Encryption at Rest files need their passphrase.** Secure external-storage containers are not supported.
- **Review imported privileges before people sign in.** Per-layout, per-value-list and per-script custom access is not decoded; recognized overall levels are imported, while unrecognized encodings give no access. Custom table and field access is imported conservatively, and record-access calculations are not decoded. `docs/moving-a-solution.md` describes the restrictions and unverified encodings.

`tabularius report <folder>` reports detected conversion and support issues; it cannot prove compatibility. `docs/known-differences.md` collects documented differences and unverified behavior. Windows execution remains unverified because native platform acceptance has not been established; see `docs/release-builds.md`.
